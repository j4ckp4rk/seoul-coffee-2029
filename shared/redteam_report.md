### 1차 수정 이력 (레드팀 지적 → 반영)

1. **전문가 가중치가 표본 안에서 평가됨**(누설) → 모든 방식을 같은 5-fold CV로 재평가. 최종 ρ가 0.183(표본 내)에서 0.199(CV)로 바뀜
2. **백테스트가 한 시점뿐** → 목표 기간이 겹치지 않는 시점 외 검증 추가(ρ 0.144, 적중률 32.4%)
3. **점수 1위(가산디지털단지)가 2022 대비 −39% 하락 상권** → 규모·추세 필터를 명시적인 깔때기로 추가하고 탈락 사유를 공개
4. **체류율 계산 오류**(0.54로 표기, 실제 0.533) → 53%로 정정
5. **종로·청계 "세운 재개발" 근거 미확인** → 주장을 삭제하고 "조사 범위에서 확정 호재 미확인"으로 수정

## 2. 클라이언트 반론 (P8) → 본문 FAQ 반영

1. 점포당 매출이 높으면 경쟁자가 몰리지 않나? → 백테스트 S2 음(−) 가중치를 공개하고, GTX 개통 전 선점과 미팅 특화로 대응
2. 객수 1.15배 가정이 틀리면? → 손익분기 136건과 −20% 적자를 공개하고, 4주 실측을 투자 조건으로 둠
3. 임대료가 비싸지 않나? → 임대료 +20%에도 흑자(7.7%)이고, ㎡당 11만 원을 계약 상한으로 둠
4. 모델 예측력(ρ≈0.2)이 낮지 않나? → 적중률(34.8% vs 무작위 25%)과 시점 외 검증을 공개하고, 다중 필터로 결정
5. 카드 추정매출을 믿을 수 있나? → 현금 누락과 법인 매출의 연령 미상 한계를 명시
