# Brief — 커피 브랜드 신규 출점 전략

- **클라이언트**: PE가 보유한 커피 전문 브랜드. 베이커리는 객단가를 올리는 보조 카테고리로만 다룸
- **질문**: 3년 뒤(2029년) 성장할 서울 상권은 어디이고, 그곳에서 어떤 매장을 열어야 돈을 버는가
- **산출물**: `docs/index.html`(한 페이지, GitHub Pages), `docs/video/pitch.mp4`(115~125초, 결론 먼저), GitHub 레포 + Pages URL

## 평가 기준 (각 10점, 목표 전 항목 9점 이상)

1. METRICS: 수요·공급·모멘텀·비용/리스크 MECE 트리, 산식·가중치·근거 표, 상관 점검, 백테스트(과거 지표 → 이후 3년 매출 성장)
2. EVIDENCE: 모든 숫자에 출처·기간·단위, `evidence.csv` 원장, 재조회 검증, 가정은 범위·근거와 함께 명시
3. INSIGHT: 통념을 뒤집는 히어로 인사이트 1개, 데이터로 재현 가능
4. CONCEPT: 컨셉 한 문장 → 상권·타깃·공간·메뉴·차별화·손익, 추적표
5. DELIVERY: 첫 화면에 결론·입지·KPI 3개(예상 연매출, 영업이익률, 투자회수기간)·영상, 영상 첫 15초에 결론

## 제약

- 데이터 날조 금지. 조회 실패한 수치는 쓰지 않거나 "가정"으로 표시
- 인증키는 `.env`에만 두고 커밋하지 않음
- 산출물에 개인정보 금지, 팀원은 `{팀원}` 자리표시자
- GitHub push 직전에 레포 이름과 공개 여부를 사용자에게 확인

## 현재 막힌 곳

Gate 0: 유효한 서울 열린데이터광장 인증키 또는 상권분석서비스 CSV가 필요함 (`shared/data_inventory.md` 참고)
