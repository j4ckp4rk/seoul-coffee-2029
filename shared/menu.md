# 메뉴 포트폴리오 (P5 · 바리스타 출신 메뉴 MD)

컨셉 인용: "미팅과 미팅 사이 30분" · 설계원칙 3 "한 번에 여러 잔 + 고급 한 잔"

## 가격 앵커 (근거)

- 상권 커피 객단가 **11,916원**(카드 1건당, 2025Q3~2026Q2, E25), 서울 상권 중앙값 7,502원(E33)의 1.59배
- 대형 프랜차이즈 기준가: 스타벅스 아메리카노 톨 **4,700원**(2025.1.24 인상, E42)
- 원칙: 아메리카노를 기준가보다 **+800원(+17%)** 높게 둔다. 상권 객단가 프리미엄(+59%)의 3분의 1 수준이라 가격 저항이 낮다고 판단(가정 A2)

## 객단가 12,000원 산출 (가정 A2)

| 항목 | 거래 1건당 수량(가정) | 평균가(원) | 금액(원) |
|---|---|---|---|
| 음료 | 1.6잔 (미팅·단체 주문) | 6,400 | 10,240 |
| 베이커리 | 0.4개 | 4,800 | 1,920 |
| **합계** | | | **12,160 → 12,000으로 반올림(보수)** |

- 1.6잔 근거: 상권 객단가 11,916원은 커피 한 잔 값의 약 2배라 단체 주문이 흔하다는 뜻(E25)
- 시나리오: 비관 11,000원 / 기본 12,000원 / 낙관 12,600원

## 원가율 29% 산출 (가정 A4)

음료 가중 평균 원가율 25% × 음료 비중 84% + 베이커리 45% × 16% = 28.2% → 폐기·시음 손실을 더해 **29%**.
원가율은 원두 kg당 가격, 우유 단가, 베이커리 납품가에 따른 업계 통상 범위(음료 17~32%, 베이커리 38~50%)를 쓴 **가정**입니다. 실제 공급 계약 단가로 교체해야 합니다.
