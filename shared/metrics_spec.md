# 지표 설계서 (P1 · Phase 1)

재현: `python scripts/collect.py && python scripts/analyze.py && python scripts/select_area.py`
산출: `data/processed/backtest.json`, `backtest_2022_2025.csv`, `corr_matrix_2022.csv`, `scores_current.csv`, `funnel.json`

## 1. 질문을 지표로

"2029년에 커피 매출이 커질 서울 상권은?" → **목표변수 = 상권 커피-음료 추정매출의 3년 연평균 성장률(CAGR)**.
분석 단위는 서울시 상권분석서비스의 상권(TRDAR_CD). 기준기간 커피 매출 3억 원 미만인 곳은 성장률 잡음이 커서 뺐습니다.

## 3. 중복 점검 (Gate 1)

2022년 표본(661개 상권), 윈저라이즈(1~99%) 후 z-score 상관계수:

| 상위 쌍 | r |
|---|---|
| S2 점포당 매출 – R2 매출 규모 | 0.71 |
| D3 직장인구 – R2 매출 규모 | 0.63 |
| D1 유동인구 – S1 커피점 밀도 | −0.60 |
| D2 20~30대 비중 – R2 매출 규모 | 0.41 |

**|r| ≥ 0.8인 쌍은 0개** → 12개 지표를 모두 유지. 기간도 모든 지표가 같은 4개 분기(기준기간)로 맞춰져 있습니다.

## 4. 백테스트 설계

- 기준기간 B = 2022년 1~4분기, 전년 = 2021년 → 목표 = 2022→2025년 커피 매출 CAGR (매출 API가 2021Q1부터라서 가장 이른 3년 창)
- 가중치 4종을 **같은 5-fold 교차검증**으로 비교(가중치는 학습 fold에서만 추정, 평가는 표본외)
  - (a) 데이터: 릿지 회귀 계수
  - (b) 전문가 사전: 분류 비중(수요 25 · 공급 25 · 모멘텀 30 · 리스크 20) × 사전 가설 부호
  - (c) 전문가 부호 보정: (b)의 비중 × 학습 데이터 상관 부호
  - (d) **최종 = (a) 50% + (c) 50%**
- 평가지표: 점수–실제 CAGR 순위상관(ρ), 점수 상위 10%가 실제 성장 상위 25%에 드는 비율(적중률, 무작위 기대치 25%)

## 5. 백테스트 결과 (5-fold CV 표본외, n=661)

| 가중치 | ρ | 상위10% 적중률 | 상위10% 평균 CAGR |
|---|---|---|---|
| (a) 데이터 릿지 | 0.217 | 36.4% | +3.68% |
| (b) 전문가 사전 | 0.022 | 25.8% | −1.29% |
| (c) 전문가 부호 보정 | 0.150 | 30.3% | +0.97% |
| **(d) 최종 블렌드** | **0.199** | **34.8%** | **+3.43%** |
| 참고: 전체 평균 | — | 25%(기대치) | −0.66% |
| 참고: 2022 매출 상위 10% | — | — | +0.81% |

점수 5분위별 실제 CAGR(최종 가중치): Q1 −6.39% · Q2 −1.01% · Q3 −0.72% · Q4 +1.66% · Q5 +3.14%

**최종안 선택 이유**: 순수 데이터(a)가 ρ가 조금 더 높지만, 한 시점(2022→2025)에 과적합될 위험이 있어 해석 가능한 전문가 구조(c)와 반반 섞었습니다. 표본외 성능 손실은 ρ 0.018로 작습니다. 전문가 사전(b)은 사실상 무작위 수준이었습니다(ρ 0.022). 가설 부호 5개가 데이터와 반대였기 때문입니다(S1·S3·M3·R1·R2). 가설이 틀렸다는 것 자체가 인사이트 근거입니다(`insights.md`).

**강건성**
- 시점 외 검증: 2022→2024로 가중치 학습 → 2024 지표로 2024→(2025Q3~2026Q2) 성장 예측. 목표 기간이 겹치지 않음. ρ 0.144, 적중률 32.4%(n=681)
- 안정성: 같은 가중치로 2023 지표 → 2023→2025 성장. ρ 0.247, 적중률 35.8%(n=672)

**한계**: ρ 0.2 수준은 "순위를 대략 맞히는" 정도입니다. 그래서 점수 하나로 결정하지 않고 아래 깔때기에서 규모·추세·개발 호재를 함께 봅니다.
